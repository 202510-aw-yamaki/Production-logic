# 04_BREEDING_LOGIC.md

## 基本方針

生産された段階で、産駒のステータスはすべて決まる。

## 5代血統表

- 必ず5代血統表を使う。
- インブリード判定は5代血統内のクロスを見る。

## インブリード判定

5代血統内で同一祖先が複数回出現した場合にクロスとする。

| 世代 | 寄与率 |
|---:|---:|
| 1代前 | 50.00 |
| 2代前 | 25.00 |
| 3代前 | 12.50 |
| 4代前 | 6.25 |
| 5代前 | 3.125 |

例：

- 3x4 = 12.50 + 6.25 = 18.75

## 18.75%超の扱い

- 血が濃くなるほど体質にデバフをかける。
- 18.75%超のクロスがある場合、体質へのデバフを強くする。

## アウトブリード

- 5代血統内にクロスがない場合、アウトブリードとする。
- アウトブリードの場合、体質はC以上保証。
- 体質の内部値は最低32から決める。

## 良い配合 / とても良い配合

| 判定 | 条件 |
|---|---|
| 父系条件 | 父系サイアーラインが6種類以上 |
| 牝系条件 | メアーライン判定用ラインが3種類以上 |
| 良い配合 | 父系条件または牝系条件のどちらかを満たす |
| とても良い配合 | 父系条件と牝系条件の両方を満たす |

## 産駒能力の最低保証

| 配合評価 | 各ステータス最低値 |
|---|---:|
| normal | 0 |
| good | 16 |
| very_good | 32 |

## 体質

- 体質は基本ランダム。
- アウトブリードならC以上保証。
- インブリードがあると体質にデバフ。
- 18.75%超のインブリードがあると強めのデバフ。

## 恐怖心

- 自身のスピードから想定される最高速度より速い速度を出そうとした場合、恐怖心判定が入る。
- `random(0, 127) > fear` のとき、速度が出せなくなる想定。
- 恐怖心値が低いほど抑制が起きやすい。
- 欧州寄りの血統では低く出やすい。
- 日本寄りの血統では高く出やすい。
