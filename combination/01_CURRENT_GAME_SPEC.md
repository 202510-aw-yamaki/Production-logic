# 01_CURRENT_GAME_SPEC.md

## ゲーム概要

ダビスタ風の競馬配合Webゲーム。

## MVPで実装するもの

- 種牡馬一覧
- 繁殖牝馬一覧
- 配合画面
- 5代血統表
- 配合評価
- 生産結果
- 自家生産馬管理
- localStorage保存
- JSON出力
- JSON読み込み
- 未保存時のブラウザ終了確認

## MVPで実装しないもの

- 調教
- レースシミュレーション
- 出馬表の印
- 友人対戦コード
- レース演出
- 詳細な疲労、故障、体調管理

## 能力値

競走馬の能力は内部的に0〜127で保持する。

| 能力 | 意味 |
|---|---|
| スピード | レース中スピード |
| スタミナ | レース中スタミナ |
| パワー | 坂や重い馬場への適性 |
| 根性 | 競り合いの強さ |
| 瞬発 | 最高速への到達速度 |
| 持続力 | 1完歩ごとの速度減衰 |
| 気性 | 気性 |
| 恐怖心 | 想定以上の高速状態で速度を出し切れるかに関わる閾値 |
| 体質 | 日常の体質、飼い食い、体調維持 |
| 健康 | 脚部の丈夫さ |
| 馬場適性 | 芝、ダート、万能 |

## ランク

| ランク | 内部数値 |
|---|---:|
| A | 96〜127 |
| B | 64〜95 |
| C | 32〜63 |
| D | 0〜31 |

## 能力表示

- 能力値は内部保持する。
- MVP通常画面では能力値を直接表示しない。
- 開発確認用のdebug表示は、切り替え式であれば実装可。

## 種牡馬パラメータ

| パラメータ | 内容 |
|---|---|
| 距離適性 | 下限1000m〜上限3600m |
| 気性 | 競走馬時代の気性を参照 |
| 底力 | 瞬発力、根性、持続力の高い2つを基準 |
| 頑健 | 競走馬時代の健康を参照 |
| 実績 | 競走馬時代の成績と種牡馬実績を参照 |
| 安定 | 産駒のばらつき |
| 馬場適性 | 芝、ダート、万能 |

## 繁殖牝馬パラメータ

| パラメータ | 内容 |
|---|---|
| スピード | A〜D |
| スタミナ | A〜D |
| 馬場適性 | 芝、ダート、万能 |

## 自家生産繁殖枠

- 自家生産種牡馬：最大3頭
- 自家生産繁殖牝馬：最大5頭
- 馬の寿命はなし
