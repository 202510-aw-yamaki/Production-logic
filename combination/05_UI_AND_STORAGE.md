## 保存方式

### localStorage

- ブラウザ内にセーブデータを保存する。
- キー名はバージョン付きにする。

例：

```ts
const SAVE_KEY = "horse_breeding_game_save_v1";
```

### JSON出力

- 現在のセーブデータをJSONファイルとしてダウンロードできるようにする。
- ファイル名には日時を含める。

### JSON読み込み

- JSONファイルを読み込んで復元できるようにする。
- バージョン違いの場合は警告する。
- 不正JSONの場合は読み込みを拒否する。

## 未保存時のブラウザ終了確認

- アプリ状態に `isDirty` を持つ。
- localStorage保存またはJSON出力後に `isDirty = false`。
- 生産、繁殖入り、削除、読み込みなどで `isDirty = true`。
- `beforeunload` で確認を出す。

```ts
window.addEventListener("beforeunload", (event) => {
  if (!isDirty) return;
  event.preventDefault();
  event.returnValue = "";
});
```
